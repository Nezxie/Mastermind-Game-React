This is a simple game inspired by a board game Mastermind.
In the game you have to guess a code made by onother player (here a computer) by arranging colorfull beads.
The opponent then marks the correct beads with green and the beads that you guessed correctly but are on wrong positions with yellow.
You have 10 guesses (but I guess I might limit that later).
New features:
- control over how many colors/options are possible for a bead
- control over board size (although this needs some limit on smaller mobile devices)

Link to live preview: https://nezxie.github.io/Mastermind-Game-React/
